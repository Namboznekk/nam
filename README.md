# Nam Nguyễn — Portfolio cá nhân

Website giới thiệu bản thân bằng tiếng Việt, phong cách vũ trụ công nghệ tím-xanh neon.

## Xem website
Sau khi bật GitHub Pages, website sẽ ở địa chỉ:
https://namboznekk.github.io/nam/

## Cách bật GitHub Pages
1. Mở tab **Settings** của repository.
2. Chọn **Pages** ở thanh bên.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch **main** và thư mục **/(root)**, rồi nhấn **Save**.
5. Chờ GitHub triển khai website trong vài phút.

## Chỉnh sửa website
Mở file `index.html` và sửa nội dung trong các phần Về mình, Sở thích, Kỹ năng, Mục tiêu. Website sử dụng HTML, CSS và JavaScript thuần, không cần cài thư viện.
